# DK AI Router

This router applies to work under `Modules/DK/`.

## Required context

After repository startup, read:

1. `Modules/DK/docs/ai/README.md`
2. `Modules/DK/docs/ai/manifest.yaml`
3. `docs/project/ai/TMS-AI-PROFILE.md`
4. `Modules/DK/docs/ai/GOVERNANCE-PROFILE.md`

Then load only the owner-local index and records required by the task.

## Scope

DK owns its target-module-specific technical, product, operational, reference, and lifecycle documentation. Root application behavior, cross-module contracts, shared Acceptance runtime, repository lifecycle records, and concerns shared outside DK remain project-owned.

Notification Delivery (ND) is reserved as a future Component inside DK. It is not an independent Nwidart module or documentation owner.

The local profile tightens shared governance but does not replace it, override accepted Canonical decisions, or expand an approved Pack.

Do not modify DK source or tests without an accepted DK-local Pack that explicitly lists those files. Do not access a real target or store target configuration or secrets. Do not commit without separate operator authorization.
