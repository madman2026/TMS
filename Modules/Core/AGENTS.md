# Core AI Router

This router applies to work under `Modules/Core/`.

## Required context

After repository startup, read:

1. `Modules/Core/docs/ai/README.md`
2. `Modules/Core/docs/ai/manifest.yaml`
3. `docs/project/ai/TMS-AI-PROFILE.md`
4. `Modules/Core/docs/ai/GOVERNANCE-PROFILE.md`

Then load only the owner-local index and records required by the task.

## Scope

Core owns its module-specific technical, product, operational, reference, and lifecycle documentation. Root application behavior, cross-module contracts, repository lifecycle records, and concerns shared outside Core remain project-owned.

The local profile tightens shared governance but does not replace it, override accepted Canonical decisions, or expand an approved Pack.

Do not modify Core source or tests without an approved Pack that explicitly lists those files. Do not commit without separate operator authorization.
