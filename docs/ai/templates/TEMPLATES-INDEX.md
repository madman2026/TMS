# TEMPLATES-INDEX

Templates define executable file formats. Do not duplicate full template structures in explanatory files.

For template synchronization rules, read:

- `docs/ai/rules/DOCUMENT-MAINTENANCE-RULES.md`

| `docs/ai/templates/REMEDIATION-PACK-TEMPLATE.md` | Source of truth for Remediation Pack format. | Read when creating a Remediation Pack. |
